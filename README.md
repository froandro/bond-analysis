# Облигационный Арбитраж

Профессиональный калькулятор для расчёта доходности облигаций. Данные подтягиваются напрямую с Московской биржи (MOEX).

## Зачем это?

Вы покупаете облигацию и хотите понять реальную доходность. Не текущую (купон/цена), а **чистую** — с учётом налогов, комиссий, НКД и времени до погашения. Этот калькулятор считает:

- **YTM** — доходность к погашению с реинвестированием купонов
- **Net Yield** — то же самое, но после вычета налогов
- **Срок окупаемости** — когда купоны покроют премию
- **Общую прибыль** за всё время
- **График** денежных потоков по месяцам
- **Детальную таблицу** каждой выплаты

## Как пользоваться

### 1. Найти облигацию

Введи тикер, ISIN или название в поиск. Калькулятор найдёт её на MOEX и подставит цену, НКД, дату погашения и расписание купонов.

### 2. Ввести свои параметры

- **Объём инвестиций** — сколько денег выделяешь на покупку
- **Налог** — 13% для резидентов (или 0% для ИИС-Б)
- **Комиссия** — обычно 0.01–0.1% у брокера

Остальное (цена, номинал, НКД, даты) подставится автоматически.

### 3. Изучить результат

Справа появятся:

- **Чистая доходность (NET)** — главный показатель
- **YTM** — грязная доходность
- **Окупаемость** — когда премия окупится
- **Количество облигаций** — сколько влезет в бюджет
- **График** — как растёт капитал
- **Таблица** — каждая выплата с разбивкой
- **Кнопка PDF** — сохранить отчёт в виде печатного документа

npm run dev

```bash
npm run build
```

Готовые файлы в папке `dist` — их можно залить на любой хостинг.
