# Облигационный Арбитраж

Калькулятор для анализа доходности облигаций с интеграцией MOEX API.

## Возможности

- Поиск облигаций на Московской бирже по тикеру, ISIN или названию
- Расчёт YTM (доходность к погашению) методом XIRR
- Чистая доходность с учётом налогов и комиссий
- Срок окупаемости (премия над номиналом)
- График денежных потоков и накопления капитала
- Поддержка амортизируемых облигаций
- Детализированная таблица выплат
- Экспорт отчёта в PDF (печать)
- Тёмная и светлая темы

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

## Сборка

```bash
npm run build
```
